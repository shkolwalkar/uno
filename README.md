# Project Name
Uno

**Status:** Archived. Built for Advanced CS Topics/Projects [2024-2025]. Worked at submission; dependencies may be outdated.

## About
It's Uno in Java!

This essentially works the same as normal Uno.

Cool Features:
- You can customize # of players and # of cards in starting hand
- Multithreading for the 'uno' call! A timer runs while the computer waits for input on the console, where you type 'Uno!'
